# Budgeting App — Product Backlog

This backlog uses the **MoSCoW prioritization method** and expresses functionality as **user stories**.

- **Must Have** — Essential for the application to function as an MVP.
- **Should Have** — Important features, but the MVP can still function without them.
- **Could Have** — Useful improvements that can be added if time allows.
- **Won't Have (for now)** — Explicitly outside the current scope.

## Must Have

**As a user, I want to...**

- [ ] add an income transaction, so that I can keep track of money coming in.
- [ ] add an expense transaction, so that I can keep track of money going out.
- [ ] my transactions to be saved, so that my financial data is still available when I reopen the application.
- [ ] view my transaction history, so that I can see where my money has come from and gone.
- [ ] edit a transaction, so that I can correct mistakes or update its details.
- [ ] delete a transaction, so that I can remove incorrect or unwanted entries.
- [ ] assign a category to a transaction, so that I can organize my income and expenses.
- [ ] see my current balance, so that I know how much money I have available.
- [ ] see my total income and total expenses, so that I can quickly understand my financial situation.
- [ ] the application to validate the information I enter, so that invalid transactions are not saved.
- [ ] clear feedback when something goes wrong, so that I understand what happened and what I can do next.

## Should Have

- [ ] view a monthly overview of my finances, so that I can understand my spending for a specific month.
- [ ] set a spending limit for a category, so that I can control how much I spend.
- [ ] see how much I have spent in each category, so that I can identify where most of my money goes.
- [ ] filter transactions by date, so that I can focus on a particular period.
- [ ] filter transactions by category, so that I can review a specific type of spending or income.
- [ ] search my transactions, so that I can quickly find a specific entry.
- [ ] a dashboard with key financial information, so that I can understand my finances at a glance.
- [ ] be warned when I exceed a budget, so that I know when I am spending more than planned.

## Could Have

- [ ] view charts of my income and expenses, so that I can understand financial trends more easily.
- [ ] create recurring transactions, so that I do not have to manually enter regular payments every time.
- [ ] create custom categories, so that I can organize transactions in a way that suits me.
- [ ] use a dark theme, so that I can choose an interface that is more comfortable for me.
- [ ] export my transactions to CSV, so that I can use my financial data in other applications.
- [ ] import transactions from CSV, so that I can add existing financial data more easily.
- [ ] set savings goals, so that I can track progress toward things I want to save for.
- [ ] reminders for important financial tasks, so that I do not forget them.
- [ ] see additional financial statistics, so that I can better understand my spending habits.

## Won't Have — Current Scope

- connect my bank account directly, so that transactions are imported automatically.
- track investments, so that I can manage my portfolio within the application.
- track cryptocurrency, so that I can include crypto assets in my finances.
- AI-generated financial advice, so that I can receive personalized financial suggestions.
- share a budget with other users, so that multiple people can manage the same finances.
- use the application on my phone, so that I can manage my budget while away from my computer.
- my data to synchronize between devices, so that I can access the same budget everywhere.
